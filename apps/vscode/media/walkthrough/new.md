# Create a board

Click [Create empty board](command:eventStorming.newBoard), pick a name and a folder, and the new
`.storm` file opens as a board. You can also run **Event Storming: New Empty Board** from the
Command Palette (`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux), or choose
**File › New File… › Event Storming Board**.

The file is plain text and stays the source of truth: save, Git, diff and undo all work on it.
Pick a sticky from the palette at the top to start; the hint in the middle of an empty board
offers **Insert example** as well.
