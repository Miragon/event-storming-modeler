# Open the example

Click [Create board from example](command:eventStorming.newBoardFromExample) to save the example
as a new file. It is a design-level board of a checkout flow: an actor issues a command, an
aggregate handles it, a domain event follows, a policy reacts, and a read model, an external
system and a hotspot complete the picture.

Every sticky colour has a meaning; **Learn the basics** explains them.
