# Create your first board

The quickest way to see an Event Storming board is to open the built-in example. Just click:

[Create board from example](command:eventStorming.newBoardFromExample)

Want to start from a blank canvas instead? Click [Create empty board](command:eventStorming.newBoard).

You can also run either command any time from the Command Palette
(`Cmd+Shift+P`, or `Ctrl+Shift+P` on Windows and Linux) by typing _"Event Storming"_.

Either way you get a graphical editor backed by a plain-text file. Save it as `.storm` and that
text file stays the source of truth, so Git, save, and diff all keep working. Use the palette on
the left to place stickies — domain events, commands, actors, aggregates and more — and drag
arrows between them to tell the story of your domain.
